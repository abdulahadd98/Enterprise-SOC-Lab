# Security and Publication Notes

This repository is intended for a public technical portfolio.

Before committing screenshots or exported configuration files, review them for sensitive information.

Do not publish:

- Client secrets
- Passwords
- Access tokens
- Private keys
- Azure subscription IDs unless specifically required
- Tenant IDs unless specifically required
- Workspace IDs
- Machine IDs
- Authentication URLs containing secrets
- Personal email addresses where unnecessary

A temporary Azure Arc onboarding credential was used during the lab and later revoked. It must never be included in this repository.

Only sanitized evidence should be published.

All security testing in this project was performed inside an authorized private lab.
